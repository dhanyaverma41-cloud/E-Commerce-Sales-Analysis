# E-Commerce-Sales-Analysis

An R-based data analysis project to analyze e-commerce sales and identify important sales trends and customer purchasing patterns.

— Tools & technologies used: R, dplyr, ggplot2
— Performed data cleaning, analysis, and visualization on simulated e-commerce sales data to calculate key performance indicators such as total sales, total orders, total customers, and average order value. Analyzed sales across different product categories and generated monthly sales trends to understand overall business performance.
